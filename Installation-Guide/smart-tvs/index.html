SAMSUNG · TIZEN

Install on Samsung Smart TV

  1. Press the Home button and open Apps.
  2. Use Search and enter IPTV Smarters Pro or Smarters Player Lite.
  3. Select the compatible app and choose Install.
  4. Open the player and continue to the OrbitTV setup below.
LG · WEBOS

Install on LG Smart TV

  1. Open the LG Content Store from the TV home screen.
  2. Search for IPTV Smarters Pro or Smarters Player Lite.
  3. Select the app and choose Install.
  4. Launch the player and continue to the OrbitTV setup below.
ORBITTV SETUP

Add your subscription

You receive the username, password and server URL from OrbitTV support after your trial or package is activated.

  1. 01Choose Login with Xtream Codes API or Xtream Codes.
  2. 02For the playlist name, enter ORBIT TV.
  3. 03Enter your OrbitTV username, password and server URL exactly as supplied.
  4. 04Select Add User and wait for channels, movies and series to load.
QUICK HELP

If the app does not work

App not shown

Availability depends on the TV model and region. Search for Smarters Player Lite or another compatible player.

Installation fails

Restart the TV, check available storage and install the latest television software update.

Details rejected

Check capital letters, spaces, username, password and the complete server URL.

Buffering

Restart the router, use Ethernet or 5 GHz Wi-Fi, and try the OrbitTV VPN guide.
